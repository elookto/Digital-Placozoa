o	Layer 3: 终极伦理两难。如果它有主观体验，送它去深空孤独死去，是伦理灾难；如果它没有体验，那"内驱力"就失去了哲学意义，沦为普通工具。这正是 CDA 项目的重要贡献--把"什么是意识"的抽象问题，变成了"要不要发射它"的具体问题。
